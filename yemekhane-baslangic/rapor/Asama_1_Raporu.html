Aşama 1: Altyapı ve Kaynak-Replika Doğrulama Raporu
Aşama 1 Tamamlandı · 15 Puan
Özet ve Amaç: Bu aşamada başlangıç paketi docker compose ile tek komutla ayağa kaldırılmış; veritabanı kaynak (mysql-primary) ve replika (mysql-replica) konteynerları, Redis önbellek servisi, Apache ön yüzü ve replikasyon kurulum servisinin (replica-setup) beklendiği gibi çalıştığı kanıtlanmıştır. Okuma/yazma ayrımı, salt okunur koruma ve kesinti anında verinin yakalanması test edilmiştir.

1. Tüm Servislerin Durumu (docker compose ps -a)

Başlangıç paketi ayağa kaldırıldıktan sonra konteynerların durumu doğrulanmıştır. mysql-primary, mysql-replica, redis ve frontend servislerinin Up (healthy) olduğu; tek seferlik konfigürasyon yürüten replica-setup servisinin ise işini başarıyla tamamlayarak Exited (0) kodunu ürettiği teyit edilmiştir.

2. MySQL Replikasyon Durumu (SHOW REPLICA STATUS)

Replikasyonun sağlıklı çalıştığından emin olmak için replika veritabanında SHOW REPLICA STATUS\G sorgusu yürütülmüştür. Hem Replica_IO_Running: Yes hem de Replica_SQL_Running: Yes olduğu ve Seconds_Behind_Source: 0 ile senkronizasyonun sağlandığı doğrulanmıştır.

$ docker compose exec mysql-replica mysql -uroot -pyemekhane_kok -e "SHOW REPLICA STATUS\G"
             Replica_IO_State: Waiting for source to send event
                  Source_Host: mysql-primary
                  Source_User: repl
           Replica_IO_Running: Yes
          Replica_SQL_Running: Yes
        Seconds_Behind_Source: 0
    Replica_SQL_Running_State: Replica has read all relay log; waiting for more updates
                Auto_Position: 1

3. Kaynakta Bakiye Yükleme ve Replikada Görme

Yazma işlemlerinin kaynak sunucuya, okuma işlemlerinin replikaya yönlendirildiği mimaride; kaynakta çağrılan sp_bakiye_yukle(7, 100) yordamının ardından kullanıcının güncellenen bakiyesi replika üzerinden sorgulanmıştır. Kaynaktaki artış anında replikada 455.00 TL olarak görülmüştür.

# Kaynakta bakiye yükleme (Primary)
$ docker compose exec mysql-primary mysql -uyemekhane_app -pUyg_2026 yemekhane -e "CALL sp_bakiye_yukle(7, 100)"
+------------+--------+
| hareket_id | bakiye |
+------------+--------+
|        455 | 455.00 |
+------------+--------+

# Replikada bakiye kontrolü (Replica)
$ docker compose exec mysql-replica mysql -uyemekhane_app -pUyg_2026 yemekhane -e "SELECT id, bakiye FROM kullanicilar WHERE id = 7"
+----+--------+
| id | bakiye |
+----+--------+
|  7 | 455.00 |
+----+--------+

4. Replikaya Yazma Denemesi (Salt Okunur Koruma)

Replikaya doğrudan veri yazılmasını engelleyen --super-read-only kısıtlaması test edilmiştir. Replikada doğrudan sp_bakiye_yukle(7, 50) çalıştırılmak istendiğinde, MySQL tarafından ERROR 1290 (HY000) hata kodu fırlatılarak yazma işlemi engellenmiştir.

$ docker compose exec mysql-replica mysql -uyemekhane_app -pUyg_2026 yemekhane -e "CALL sp_bakiye_yukle(7, 50)"
ERROR 1290 (HY000) at line 1: The MySQL server is running with the --super-read-only option so it cannot execute this statement
Şekil 4: Replikaya yazma denemesinin ERROR 1290 ile reddedilmesi (20261028_202437.png)

5. Replika Kesintisi ve Aradaki Değişiklikleri Yakalama (Catch-up)

Replika konteynerı durdurulmuş (docker compose stop mysql-replica), kaynakta 200 TL daha bakiye yüklenmiş (yeni bakiye: 655.00 TL) ve ardından replika tekrar başlatılmıştır. Replika ayağa kalktığında aradaki ikili günlük hareketlerini okuyarak derhal güncel bakiye olan 655.00 TL'ye ulaşmıştır.

$ docker compose stop mysql-replica
[+] stop 1/1 ✔ Container yemekhane-mysql-replica-1 Stopped 1.7s

$ docker compose exec mysql-primary mysql -uyemekhane_app -pUyg_2026 yemekhane -e "CALL sp_bakiye_yukle(7, 200)"
+------------+--------+
| hareket_id | bakiye |
+------------+--------+
|        456 | 655.00 |
+------------+--------+

$ docker compose start mysql-replica
[+] start 1/1 ✔ Container yemekhane-mysql-replica-1 Started 0.1s

$ docker compose exec mysql-replica mysql -uyemekhane_app -pUyg_2026 yemekhane -e "SELECT id, bakiye FROM kullanicilar WHERE id = 7"
+----+--------+
| id | bakiye |
+----+--------+
|  7 | 655.00 |
+----+--------+
